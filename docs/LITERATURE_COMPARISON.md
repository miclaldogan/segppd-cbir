## Is anything genuinely comparable to our numbers?
**No.** Our headline is Hit@1 (= P@1) of a *closed-set retrieval* protocol over **75** of the 101 SegPPD-101 classes (train 772 / gallery 809 / 225 locked queries; pooled B+C 0.794; external PlantSeg 11-class 0.608).
* Entries 1-2 are **segmentation** (mIoU); entry 3 is **zero-shot classification** (accuracy); mIoU/accuracy cannot be ranked against Hit@1 even on the same images.
* Entries 4-6 are **retrieval** studies and are conceptually closest, but each uses different data (PlantVillage laboratory images, self-collected sets, PlantDoc), different class counts, different splits and different mAP / Top-1 definitions; PlantVillage-type results (MAP > 0.99) reflect an easy single-leaf laboratory setting and are not evidence about in-the-wild difficulty. Entry 5's PlantDoc MAP (0.820, in-the-wild web images) is the nearest in difficulty, but its protocol and class set differ from ours, so it is context, not a benchmark.
* No published result on the identical SegPPD-101 retrieval protocol was found, therefore **no state-of-the-art claim is made**.
