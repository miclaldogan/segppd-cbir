## Known caveats
* The headline CI [0.756, 0.856] comes from `protocolBC_hit1_summary.csv` (seed-averaged per-query P@1, class bootstrap, seed 42); earlier notes quoted [0.754, 0.856] from an equivalent computation with a different bootstrap draw - docs were harmonised to 0.756.
* Per-class "k/3" bars for the proposed model use the 3-seed mean rounded to the nearest integer.
* The 3-seed "headline" averages single-seed results; its CI is a class bootstrap of the seed-averaged per-query P@1, so it does not capture seed variance separately (individual seeds are listed).
* `docs/CBIR_RESEARCH_REPORT.{docx,pdf}`, `report/figs/dataset_samples.png`, `report/figs/retrieval_examples.png` contain dataset photographs whose underlying rights are undocumented; they are git-ignored and should not be published.
