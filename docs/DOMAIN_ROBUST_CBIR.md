## 1. Diagnosis of the external gap (C1) - 1,485 strict external queries, D5ck models (3 seeds)
Headline numbers: SegPPD Protocol B+C pooled Hit@1 0.794 (75 classes) vs external **0.608 class-macro / 0.540 query-weighted** (11 classes). The same 11 classes inside SegPPD give 0.788 (Protocol B test) / 0.773 (C test), so the **class subset explains only ~0.00-0.03 of the gap; ~0.17 is a source/domain effect** (`diag_indomain_same_classes.csv`, `diag_summary.json`, Figure `C3_internal_vs_external`).
Error factors (`diag_by_*.csv`, Figure `C1_error_factors`; seed-mean Hit@1):
* **crop/disease** (n): apple 0.288 (389; apple scab 0.272, apple rust 0.316), grape 0.310 (116), tomato 0.557 (402; leaf mold 0.366, late blight 0.686, bacterial spot 0.634), soybean 0.652 (117), bean 0.503 (108), cucumber 0.842, coffee 0.809, banana 0.873, strawberry 1.000. Apple is 26% of the query set, so the query-weighted mean (0.540) is lower than the class-macro (0.608).
* **dominant confusions** (queries/seed): tomato leaf mold -> tomato late blight 80; apple rust -> pear rust 51; bean rust -> bean angular leaf spot 45; apple scab -> pear scab 39; tomato late blight -> tomato mold 30; grape black rot -> grape healthy 25. Several are **cross-crop label proximity** (apple vs pear classes exist in SegPPD with near-identical symptoms), not domain artefacts.
* **resolution** (min side, px): <300 0.585, 300-500 0.524, 500-800 0.516, >800 0.561 - no monotone effect. **source host**: 0.48-0.69 across the six most frequent hosts - small effect. **PlantSeg mask-area ratio** (valid mask field of PlantSeg): <=0.05 0.428, 0.05-0.15 0.479, 0.15-0.30 0.566, >0.30 0.670: smaller annotated regions are retrieved worse externally (confounded with disease/organ; inside SegPPD no such trend was found earlier).
* **organ - PROVISIONAL.** No organ field exists in PlantSeg and organ was not inferred from class names. A random stratified sample of 121 external queries (<=11 per class, seed 3, ids in `organ/sample_ids.csv`) was annotated by **one annotator (an AI assistant) from the images**; labels are in `organ/organ_labels.csv` and are **not independently verified** (needs a human check before citing). Result: leaf-dominant n=76 Hit@1 0.675; fruit-dominant n=23 **0.246**; mixed n=9 0.296; whole plant n=7 0.429 (stem n=1, other n=5 not shown). Within disease: grape black rot fruit n=7 0.19 vs leaf n=4 1.00; apple scab fruit n=7 0.14; tomato late blight fruit n=7 0.48. SegPPD references are leaves, many PlantSeg images of the same labels are fruit/berries: an **organ mismatch** is a plausible main driver (confounded with disease type; sample small).
* **background type, lesion size from valid masks (SegPPD side):** no background labels exist; lesion-size analysis of the SegPPD side was done earlier (no consistent effect). Not repeated.
* Examples kept (local only, dataset photographs): `figures/C5_external_examples_LOCAL_ONLY.png` (apple rust -> pear rust, grape black rot fruit retrieved as unrelated leaves, tomato leaf mold -> late blight).

## 2. Domain-robust metric learning (C2): training-only augmentation
Loss = Proxy-Anchor (alpha 32, delta 0.3, the Track A dev-selected loss); everything else as Track A. Variants add one perturbation family to the Track A recipe ("base"): **color** (jitter 0.35/0.35/0.30/0.04), **res** (random down/up-sampling 96-224 px, blur, JPEG 40-95), **geo** (crop scale 0.5-1, rotation 20 deg, aspect 0.75-1.33), **robust** (all moderate families). No mask-based background replacement was used (SegPPD masks mark the annotated target region, not a reliable foreground/background split for whole-leaf classes). Selection on **SegPPD dev only**: base 0.820, color 0.827, res 0.820, geo 0.740, robust 0.793 (seed 0); tie band (one query) = {base, color, res} -> color by dev mAP. `color` and `robust` were repeated with seeds 1-2.

## 3. Global + local-feature retrieval (C3)
Procedure (deterministic, label-free and mask-free at inference): global exact L2 on the 256-D Proxy-Anchor embedding -> top-M (M = 20, 50) -> symmetric Chamfer similarity of L2-normalised last-layer patch tokens (16x16, no flip) -> score = alpha*cos_global + (1-alpha)*S_local over the top-M; ranks below M keep the global order. 3 seeds (Track A Proxy-Anchor checkpoints). Cost: patch tokens 256 x 768 fp16 = 393 KB/image (318 MB for the 809-image gallery); local stage 1.3-1.4 ms/query for M=20, 3.3-3.5 ms for M=50 on top of the 0.26 ms global search (GPU, median).
**Dev-only selection (registered rule) chose "no reranking"**: dev Hit@1 0.820 (global) vs 0.816 (M=20, alpha 0.5) / 0.813 (alpha 0.75); mAP 0.757 vs 0.747 / 0.756 - inside the one-query tie band, higher mAP wins. Pure local matching (alpha 0) is worse than global everywhere (dev 0.740, B 0.802, external 0.601). The blend is shown for completeness (all **exploratory**, `local_rerank_PA_summary.csv`, `local_rerank_paired.csv`, Figure `C4_global_vs_local_rerank`):

| set | global Hit@1 | M=20, alpha 0.5 | paired diff [95% class-bootstrap CI] | M=20, alpha 0.75 | paired diff |
|---|---|---|---|---|---|
| dev (selection) | 0.820 | 0.816 | -0.004 [-0.042, +0.031] | 0.813 | -0.007 [-0.033, +0.016] |
| Prot. B test (expl.) | 0.825 | 0.850 | +0.025 [+0.003, +0.049] | 0.842 | +0.016 [+0.003, +0.030] |
| Prot. C test (expl.) | 0.782 | 0.804 | +0.022 [-0.002, +0.049] | 0.796 | +0.013 [-0.009, +0.036] |
| external PlantSeg (expl.) | 0.618 | 0.635 | +0.018 [-0.012, +0.050] | 0.630 | +0.013 [-0.009, +0.041] |
Hit@1 rises about 2 points on all three consumed sets (significant only on Protocol B), while P@10 and mAP stay equal (alpha 0.75: mAP 0.755 vs 0.757 dev) or drop slightly (alpha 0.5). The dev set did not support the gain and the configuration shown was looked at after seeing exploratory numbers, so this is a **hypothesis for a fresh test, not a validated improvement**.

## 4. Conclusions
Do the domain-robust methods improve retrieval? Augmentation: **no**. Local reranking: **no on the selection set; +~0.02 Hit@1 on exploratory sets**, unconfirmed. Do improvements transfer beyond dev? Not demonstrated. Likely drivers of the external gap: organ mismatch (provisional), crop/label proximity (apple-pear), tomato leaf mold vs late blight - which call for target-domain data or organ-aware references (Track B shows PlantSeg supervision lifts accuracy to ~0.85 on its own 98-class protocol), not for more source-side augmentation.
