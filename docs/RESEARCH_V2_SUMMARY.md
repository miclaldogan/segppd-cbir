All experiments: DINOv2-B (last 4 blocks trained, d=256, exact L2). Namespace `artifacts/research_v2/` (configs, seeds, checkpoint hashes, curves, per-query CSVs, figures; `registered.json` in each track written before the runs). Historical results (Protocol A/B/C, ChatLeaf, report v1) untouched. **Protocol B/C tests and the PlantSeg external/ChatLeaf images were already inspected: everything on them is exploratory; no new independent test result is claimed.** The only selection sets were the SegPPD dev set (Tracks A, C) and the official PlantSeg Validation split (Track B).

## The eight questions
1. **Best DINOv2-B Hit@1 among the three losses:** Proxy-Anchor (alpha 32, delta 0.3): dev 0.820 +/- 0.007, B-test 0.825, C-test 0.782 (SupCon 0.820 / 0.806 / 0.771; ArcFace 0.776 / 0.793 / 0.744), 3 seeds each, selection by dev Hit@1 with one-query tie band then mAP.
2. **Best mAP:** Proxy-Anchor 0.757 / 0.753 / 0.751 > SupCon 0.747 / 0.740 / 0.731 > ArcFace 0.703 / 0.708 / 0.696.
3. **Meaningful?** Proxy-Anchor vs SupCon: Hit@1 +0.000 / +0.019 / +0.011 (all CIs include 0), mAP +0.010 / +0.012 / +0.021 (CIs include 0) - practically equivalent (<= 2 points). ArcFace is reliably lower in mAP (-0.03 to -0.05, CIs exclude 0) and not better in Hit@1 (-0.01 to -0.04). The DINOv2-S pattern "ArcFace best at Hit@1" did **not** replicate on DINOv2-B. Selecting by Hit@1 instead of mAP changed SupCon by <= 0.007.
4. **Does CBIR beat classification under equal training information?** **No - it ties.** PlantSeg protocol P (98 classes, 1,646 identical test images): metric-learned CBIR 0.847 +/- 0.005 vs linear head on the same embedding 0.852 +/- 0.007 vs CE fine-tuning 0.847 +/- 0.008 (no consistent per-seed difference); on frozen features the classifier wins by +0.106 (0.794 vs 0.688, p ~ 3e-23). CBIR's measurable edge is ranking quality (mAP 0.834) and a smaller gallery; reference traceability and incremental gallery updates were not tested.
5. **Do domain-robust methods improve retrieval?** Training-only augmentation: no (external Hit@1 0.618 base vs 0.622 color vs 0.619 robust; paired +0.005 [-0.002, +0.011]; geometry hurts). Local patch reranking: rejected by the dev rule; on the exploratory sets it adds ~+0.02 Hit@1 (B-test +0.025 [+0.003, +0.049]; C +0.022; external +0.018, CIs include 0) with unchanged mAP at alpha 0.75.
6. **Do improvements transfer beyond the development set?** Loss ranking: Proxy-Anchor >= SupCon > ArcFace holds on dev, B and C (exploratory), but the Proxy-Anchor/SupCon gap is within noise. Augmentation: no gain anywhere. Reranking: a consistent but unconfirmed +0.02. None is confirmed on untouched data.
7. **System for best Hit@1:** Proxy-Anchor DINOv2-B global embedding (Track A, dev-selected). Local reranking (M=20, alpha 0.5) is the only candidate for a further ~2 points but needs a fresh test before being adopted. For PlantSeg-like target data with labels, a metric-learned embedding trained on that data reaches ~0.85 (Track B).
8. **System for overall retrieval quality (mAP, P@K):** Proxy-Anchor DINOv2-B global (mAP 0.757 dev, 0.753 B). Reranking does not improve mAP/P@10 (alpha 0.75: equal; alpha 0.5: slightly lower).

## Remaining gap and what is NOT shown
External source-only Hit@1 ~0.61-0.62 (11 classes) vs ~0.79-0.83 in-domain; diagnosis points to organ mismatch (provisional annotation), apple/pear label proximity and tomato leaf mold vs late blight rather than resolution/source. Not run: cross-source mixed training, independent confirmation set, organ annotation verified by a second annotator, DINOv2-L or other backbones, more than three seeds, hyper-parameter search beyond the registered grids.
**Most valuable next experiment:** a fresh, duplicate-controlled evaluation set (new split or new external source) used exactly once for the frozen candidates (Proxy-Anchor global; + local reranking) and for the target-supervised track, to confirm the loss ranking, the reranking gain and the CBIR-vs-classifier tie.
