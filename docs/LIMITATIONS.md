# Limitations
* **Small test sets:** B has 225 locked queries (3/class, 75 classes), C has 142 (1-2/class); class-bootstrap CI half-widths are ~5-8 points. The 0.80 target is met by B's point estimate (0.807) only; on C it is 0.767 and pooled B+C is 0.794 [0.741, 0.844], so it is NOT confirmed. B and C are both consumed; C's queries come from the same 75 classes and the same photo pool as B (not an independent distribution).
* **Closed-set, label-proxy relevance:** classes are seen in training; relevance = same dataset label, not verified visual/agronomic similarity; not a diagnosis tool.
* **Label noise in the source data:** 16 duplicate groups carry conflicting labels (excluded); undetected near-duplicates and mislabelled images may remain; similar categories (healthy classes of related crops, sooty mold vs canker) cap achievable Hit@1.
* **Pre-resized 256x256 images:** archive lacks original resolution/EXIF; small-lesion conclusions apply to this resized data. Occupancy = annotated target-region area (confounded with disease type; whole-leaf masks for diffuse diseases and healthy classes).
* **Protocols are not comparable:** A (train-as-gallery, large gallery, exploratory) vs B (disjoint, small gallery, locked). Cross-protocol and cross-paper numeric comparison is invalid (different data, classes, galleries, trained vs training-free).
* **Selection effects:** dev (150 queries) was used for early stopping and for choosing the loss (mAP rule), backbone size (S vs B) and fusion weights; the locked set was used once. The locked set is now consumed. The loss chosen on dev mAP (SupCon) was not the best at rank 1 for DINOv2-S on test; DINOv2-B was only trained with SupCon.
* **Single split seed for Protocol B** (4242); only training seeds were varied. Hyper-parameters were not tuned beyond the listed runs.
* **Oracle ROI** uses ground-truth masks (not available for field photos). Hybrid/ensemble gains are not statistically significant.
* **External validation covers only 11 closed-set classes** (PlantSeg, leakage-screened, no healthy classes): Hit@1 0.61 vs 0.78 in-domain on the same classes, so out-of-distribution performance is clearly lower; the effect of removed easy near-copies vs domain shift is not separable. PlantSeg and SegPPD share web sources; undetected edited copies may remain. No open-set (unseen-class) validation; no agronomic validation.
* **Rights:** Zenodo record says MIT, but the rights of the underlying web photographs are undocumented; raw images/masks are not redistributed; example grids are local-only.
* Reported training times include per-epoch dev evaluation and DataLoader augmentation; GPU nondeterminism (bf16, atomics) makes same-seed reruns differ slightly (replicates: mAP +-0.005).
